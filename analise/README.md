Análise de Dados dos Projetos
Script em Python que lê os projetos cadastrados no banco SQLite e gera
estatísticas e gráficos.

O que ele faz:
 Conta os projetos por categoria e por status
 Calcula o orçamento médio por categoria
 Salva 2 gráficos em PNG

Tecnologias:
Python, pandas, matplotlib e SQLite.
